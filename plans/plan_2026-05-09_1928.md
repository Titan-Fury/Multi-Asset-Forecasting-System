## Phase 19 plan — S3 news embeddings · A6 drift gating · S1-lite microstructure · SBI A/B benchmark

### Context (what I found)

- **News pipeline already exists end-to-end.** `omni/ingest/news.py` + `omni/ondemand/lookup.py` fetch from 7+ sources; `omni/features/sentiment.py` produces 8 sentiment columns; `features_inline.py` joins them with a `+1 BDay` lag and forward-fill. FinBERT scoring is already cached 30 days at the LLM-router layer.
- **Model feature contract is permissive**: `xgboost_5d.prepare_xy()` keeps **every** numeric column except `fwd_*`/identity. So new feature columns (`emb_*`, `microstr_*`) flow into the model with zero schema plumbing.
- **DriftMonitor exists** (`omni/modeling/drift.py`) but is never called. Orchestrator `daily.py` has no realised-error loop.
- **`scripts/daily_backtest.py` already joins predictions to realised returns** and computes per-row Brier/AUC — perfect insertion point for ADWIN.
- **Microstructure inputs already ingested**: `nse_oi.py` (PCR, max-pain), `nse_flows.py` (FII/DII), 5-min intraday bars + VWAP, 9 intraday features. Missing piece: **NSE Bhavcopy delivery %** and a dimensionality-reduced "microstructure score".
- **Embedder ready**: `omni/llm/embed_nemotron.py` (Phase 18) — 1024-d, batched, graceful fallback.

### Implementation steps

**1. S3 — News embeddings as model features (~200 LOC, 2 new files)**
- New `omni/features/news_embeddings.py`:
  - `embed_daily_news(news_raw_df, ticker, dates) -> DataFrame[date, ticker, emb_0..emb_31]`.
  - For each (ticker, date), concat the day's headlines (max 8, ranked by recency), call `embed_nemotron.embed()` once per day, then **PCA-reduce to 32 dims** (fit PCA on the corpus, persist to `data/models/news_pca.joblib`). 32 ≪ 1024 prevents tree models from drowning in features.
  - Disk-cache the raw 1024-d vectors at `data/cache/news_embed/{ticker}/{date}.npy` so we never re-embed.
- New `omni/features/news_embed_pca.py`:
  - `fit_pca(corpus_vecs, n=32)` and `apply_pca(vecs, pca)`.
- Wire into `omni/ondemand/features_inline.py` after the existing sentiment join — add 32 `emb_*` columns merged on `(ticker, date)`.
- Wire into batch path `omni/features/build.py::build_for_ticker()` behind a `news_embed=None` kwarg (default off → no break to existing trainer; opt-in for retrain).

**2. A6 — Conditional drift gating in the orchestrator (~80 LOC, 1 new file + 1 edit)**
- New `omni/modeling/drift_gate.py`:
  - `update_from_predictions(preds_df, realised_df, scopes=("h1","h5","h21")) -> dict[scope, DriftEvent|None]`. Iterates per row, computes Brier per (scope, row), feeds `DriftMonitor.load(scope).update(brier)`, persists state, and writes `data/lake/monitoring/drift_<scope>.json` with `{drifted: bool, n_seen, last_drift}`.
  - `needs_retrain(scope) -> bool` reads the persisted state.
- Edit `scripts/daily_backtest.py` (smallest surface): inside the existing per-row realised-return loop, call `update_from_predictions()` once per asset/horizon and write a single consolidated `data/lake/monitoring/needs_retrain.json` flag.
- Surface in dashboard: tiny banner in the History or Calibration tab if `needs_retrain.json` says any scope drifted (read-only, 5 lines in `app.py`).

**3. S1-lite microstructure score (~120 LOC, 2 new files)**
- New `omni/ingest/sources/nse_bhavcopy.py`:
  - Pulls `archives.nseindia.com/products/content/sec_bhavdata_full_<DDMMYYYY>.csv` (the only missing free piece). Schema: `[date, ticker, deliv_pct, deliv_qty, ttl_trd_qnty, ...]`. Normalises ticker to match our `.NS` convention, caches per day.
- New `omni/features/microstructure.py`:
  - Combines existing inputs into 6 columns:
    1. `delivery_pct_z_60d` (bhavcopy delivery vs 60-day per-ticker rolling).
    2. `oi_change_pct_5d` (from `nse_oi.py` history).
    3. `fii_dii_net_z_20d` (from `nse_flows.py`, country-level).
    4. `amihud_illiq_20d` = `mean(|ret_i| / dollar_vol_i)` over 20 days, log-transformed.
    5. `signed_vol_proxy` = Lee-Ready tick-rule on the 5-min bars (sign(price_change) × volume, summed for the day, normalised).
    6. `microstr_score` = robust z-sum of the five above (one-line composite for tree models that prefer dense features).
  - Indian-only (asset_class==`india`); returns NaN columns for non-India to avoid breaking the universal trainer.
- Wire into `features_inline.py` (on-demand, per-ticker) AFTER sentiment join.

**4. Nvidia embedder rate-limit safety (small)**
- Edit `omni/llm/embed_nemotron.py` to read the `rate_limit` from `config/llm_routes.yaml` instead of hard-coding retry sleeps (so the `rpm: 18 / rpd: 200` declared in Phase 18 actually throttles).

**5. SBI A/B benchmark harness (~150 LOC, 1 new file — the proof)**
- New `scripts/benchmark_sbi.py`:
  - Picks `SBIN.NS` (or whichever ticker is passed via `--ticker`).
  - **Backtest A — baseline**: temporarily disables the new feature families (env flag `OMNI_DISABLE_EMB=1`, `OMNI_DISABLE_MICROSTR=1`) and runs the existing `predict_ticker()` walk-forward over the last 12 months at horizon 5d. Records per-day Brier, AUC, hit-rate, mean Kelly fraction, simulated equity curve assuming Kelly-sized trades.
  - **Backtest B — new**: same loop with both features enabled.
  - Output: a printed table side-by-side **and** `docs/phase19_sbi_benchmark.md` with:
    | metric | baseline | with embeddings | with microstr | full | Δ |
  - Metrics:
    - AUC, Brier, hit-rate
    - Sharpe of the Kelly-sized PnL curve
    - Max drawdown
    - Conformal-band tightness (p90 width)
  - The harness uses **only existing modules**, just composes them, so no risk of touching the trainer.

### Sequencing rationale

S1-lite first (deterministic, fast, free) → A6 drift gating (lightweight, proves observability) → S3 embeddings last (slowest, hits API). Then SBI benchmark runs all three together. If we run out of free-tier embedder budget mid-benchmark, S1-lite alone still gives us a meaningful before/after.

## Context

**Current state:**
- `theme.py` (420 lines): glassmorphism theme with light/dark variants, INTER + JetBrains Mono fonts. Uses `--accent-glow` (cyan→violet gradient) heavily — applied to text, fills, borders, scrollbars. Cards use `backdrop-filter: blur(18px)` glass effect with hover translate + cyan glow.
- `components.py` (663 lines): `prediction_card()` is now a long sequence of HTML blocks: header → Results metrics → Horizon table → price strip → proba bar → why → pillars chart → side-by-side expanders. Each block is its own card → too many separate panels visually competing for attention.
- The styling overuses gradients (every conviction bar, every pill border, every focus state uses the cyan→violet gradient). Numbers use a different mono font but at small sizes they get lost in the gradient overload. Padding is inconsistent (some blocks `10px 14px`, others `14px 18px`, others `22px 26px`).

**What "modern + minimalist" means after researching current best-in-class fintech dashboards** (Stripe, Linear, Robinhood Web 2024, Vercel Analytics):
- **Single accent color used sparingly** — gradient only on the headline number, never on borders, dividers, scrollbars
- **Strong typography hierarchy** — fewer font sizes (4-5 max), heavier weights for primary numbers (700-800), all-caps micro-labels (10-11px, letter-spaced) for section headers
- **Consistent 4/8/12/16/24/32px spacing scale** — never arbitrary values
- **Borders, not glass** — 1px hairline borders + subtle background tint instead of blur. Glass blur is heavy and fights small text
- **Numbers are the heroes** — tabular figures (`font-variant-numeric: tabular-nums`), large weights, near-black/near-white
- **No hover translate** on cards (motion sickness with many cards on screen) — only opacity/border-color shifts
- **Rule of one focal point per section** — one accent color, one bold number, the rest neutral

## Implementation steps

### 1. Refactor `theme.py` — design tokens

Replace ad-hoc CSS with a tight token system:

**Spacing scale** → `--space-1` (4) … `--space-8` (32). Use these everywhere; no arbitrary `10px 14px`.

**Type scale** (modular, 1.2 ratio):
- `--text-micro`: 0.68rem (uppercase labels)
- `--text-xs`: 0.78rem (meta, captions)
- `--text-sm`: 0.88rem (body)
- `--text-base`: 1rem (default)
- `--text-lg`: 1.25rem (subheading)
- `--text-2xl`: 1.75rem (number heroes)
- `--text-3xl`: 2.25rem (ticker)

**New color tokens** (kept dark/light parity):
- `--surface-0`: page bg (no gradient — flat)
- `--surface-1`: card surface (slightly lighter than 0)
- `--surface-2`: hover/active surface
- `--border-subtle`: 1px hairline (e.g. `rgba(148,163,184,0.14)`)
- `--border-strong`: focused border
- `--text-primary`, `--text-secondary`, `--text-muted` (kept)
- `--accent`: single solid (not gradient) — `#06b6d4` (cyan)
- `--accent-soft`: 10% alpha tint for backgrounds
- `--positive`, `--negative`, `--neutral`

**Drop**: `--accent-glow` gradient on borders/conviction-bar/scrollbar. Keep gradient ONLY for the optional accent kicker on the ticker name (one place).

**New base classes**:
- `.card` — single canonical card: `padding: var(--space-5) var(--space-6); border: 1px solid var(--border-subtle); border-radius: 14px; background: var(--surface-1)`. NO blur, NO hover translate.
- `.card-tight` — variant with `padding: var(--space-3) var(--space-4)` for sub-cards
- `.section-label` — 0.68rem uppercase letter-spaced micro label for section headers (replaces `##### Results` h5)
- `.stat` — number-first stat block with `.stat-value` (text-2xl, weight 700, tabular-nums) + `.stat-label` (text-micro uppercase) + optional `.stat-delta` (text-xs)

**Font polish**: add `font-variant-numeric: tabular-nums` to all number-rendering classes so digit columns line up.

**Background**: replace radial-gradient on body with flat `--surface-0` + a single SOFT corner glow (cyan, 8% alpha) for atmosphere. No more two competing pink/cyan blobs.

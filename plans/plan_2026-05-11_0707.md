### Implementation steps

**Phase A — Functional bugs (HIGH severity)**

1. **`width='stretch'` → `use_container_width=True`** (35 sites total)
   - app.py: lines 246, 289, 291, 340, 348, 397, 400, 566, 606, 615, 671, 732, 761, 809, 817, 840, 846, 865, 885, 935, 947, 960, 1056, 1086, 1089, 1096, 1137, 1326
   - components.py: lines 232, 236, 303, 343, 371, 399, 1097
   - For `st.button` calls: also valid kwarg since Streamlit 1.29
   - For `st.dataframe` / `st.plotly_chart`: required since 1.28

2. **XSS hardening — escape all user-derived HTML**
   - app.py:1129 — `res.ticker`, `res.asset_class`, `res.display_name` via `html.escape()`
   - components.py:1162 — news `title`, `url`, `source` (highest risk: external feeds)
   - components.py:1071-1076 — `why_text` (model-generated)
   - components.py:270 — ticker pill
   - charts/cosmos3d.py:139 — already clipped to 10 chars but escape too
   - Add `from html import escape` import where missing

3. **Kill infinite rAF loop** (theme.py:2378-2411)
   - `.ultra-cursor` / `.ultra-cursor-follow` elements never rendered (Phase 24.1 deprecation)
   - `tickFollower()` runs `requestAnimationFrame` forever on null elements — wastes a frame every 16ms forever
   - Delete the entire cursor/follower/bindHot block

4. **Parallelize Correlations price reads** (app.py:1501-1522)
   - Currently: serial loop, up to 40 parquet reads on render
   - Fix: `ThreadPoolExecutor(max_workers=8)` like the earnings/portfolio sections already use

5. **Remove `backdrop-filter` from metric tiles** (theme.py:975-976)
   - Later rule (line 1391) overrides background with opaque gradient anyway — blur is invisible
   - Removing saves GPU on every metric card render (6-12 tiles per page)

**Phase B — CSS cleanup (MED)**

6. **Delete dead toggle remnants** (theme.py)
   - Lines 2041-2100 (Phase 24.5 toggle styling) — element now hidden
   - Lines 2186-2195 (Phase 24.8 z-index fix) — same
   - Lines 2081-2093 (`@keyframes ultra-pulse-toggle` + animation) — same

7. **Consolidate duplicate selectors**
   - `[data-testid="stMetric"]` defined 5×: keep only the last (line 1391-1432), delete 266-275 + 410-416 + 969-1008
   - `section[data-testid="stSidebar"]` background defined 4×: keep one
   - Marquee/status-pill z-index dual values (1002 then 1100): keep the override

8. **Remove unused CSS classes** (~100 lines)
   - `.fx-tilt`, `.fx-pulse`, `.fx-skeleton`, `.fx-counter`, `.bento-grid` — never applied anywhere
   - `.prediction-card`, `.accent-tint-*`, `.violet-tint-*` — orphaned
   - `.ultra-num` — JS hook for slot-roll, never emitted
   - `.ultra-cursor-hot` body class — set by JS, no CSS consumer

**Phase C — Robustness (MED)**

9. **Fix marquee global mutation** (marquee.py:52, 123-129)
   - Move `_LAST_GOOD` from module-level to `st.session_state["__marquee_lastgood"]`
   - Removes cross-session race; eliminates the dead `_FALLBACK` variable

10. **Cache TTL safety floor** (cache.py:61, 71, 81, 88)
    - Add `ttl=3600` to all four `@st.cache_data` decorators as backstop against stale-mtime corner cases (network drives, identical timestamps)

11. **Atomic file writes for searchhistory + watchlist**
    - Already use `tmp.replace()` for atomicity of the rename. The race is read→modify→write
    - Add `threading.Lock` (process-local) — covers same-Streamlit-server case, which is the realistic scenario; cross-process locks would need `filelock` (new dep — defer)

12. **Replace silent `except: pass`** (app.py:1266, 455, 542, 711)
    - Use `import logging; logging.warning(..., exc_info=True)` so failures are visible in `streamlit run` console without crashing the user

13. **Expand `prefers-reduced-motion` coverage** (theme.py:2133-2137)
    - Add catch-all: `*, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }`
    - Currently aurora, search-rotate, _glow-rotate, _cmdk-pop, tabFadeIn, ultra-fade-in-up, fx-orb-* all ignore the user setting

**Phase D — Theme propagation (MED)**

14. **Wire `--theme-accent` through `_ULTRA_FX_CSS`**
    - Sidebar header gradient (line ~1140), marquee accent (~1555), status pill (~1688), search input border (~1919) all hardcode `#38bdf8`
    - Replace with `var(--theme-accent, #38bdf8)` so Cyberpunk/Synthwave/Matrix/Nord actually reskin the chrome (currently only aurora background changes)

**Phase E — Polish (LOW)**

15. Remove `section_pick` dead variable (app.py:1300) — `st.radio` writes to `__section` via `key=`
16. Drop redundant inner `import pandas as pd` (app.py:839, 921, 1503)
17. Drop redundant `from datetime import datetime as _dt` (app.py:1369)
18. Update module docstring (app.py:12-13) — still references the deleted "Tabs:" layout
19. Add `del _root` to import cleanup (app.py:37)

**Skipping** (out of scope or low ROI):
- SRI hashes on CDN scripts — `<script type="importmap">` doesn't support `integrity` in most browsers; mitigation requires a build step
- `@property` `@supports` guards — would need a JS counter fallback for `.fx-counter`; class is unused anyway (deleted in Phase B)
- Adding `filelock` dep — single-Streamlit-process is the realistic case; threading.Lock covers it
- Streamlit `st.experimental_*` — none found, nothing to change

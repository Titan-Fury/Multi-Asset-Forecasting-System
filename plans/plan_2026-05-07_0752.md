## 2. Storage Tier (your raw-on-Drive principle)

- **Local SSD (~10–15 GB) — processed/hot data only:**
  - `data\features\` — engineered parquet feature store
  - `data\models\` — trained models, checkpoints
  - `data\predictions\` — daily prediction outputs
  - `data\cache\` — LLM response disk cache (high-IOPS, must be local)
- **Google Drive via `rclone mount Z:\` — raw data only:**
  - `Z:\raw\ohlcv\`
  - `Z:\raw\news\YYYY\MM\`
  - `Z:\raw\social\YYYY\MM\`
  - `Z:\raw\fundamentals\`
  - `Z:\raw\macro\`
  - `Z:\raw\options\`
- Daily ingest writes raw → Drive. Feature engineering reads raw → writes processed → local SSD. Day-to-day backtests/training/dashboard touch only local SSD.

## 3. rclone Security Posture

- ✅ Private Google Cloud OAuth Client ID (own quota, not shared pool)
- ❌ No `crypt` overlay (public data; avoid password-loss risk)
- ⚪ Either `rclone config password` or NTFS-only-user ACL on `rclone.conf` (user choice; both OK)
- ✅ 2FA on the Google account (manual)

## 4. Multi-LLM Router (the v1 differentiator)

Module: `omni\llm\` with `router.py`, `cache.py`, `ratelimit.py`, `types.py`, and `backends\{finbert,ollama,openrouter,cortex}.py`.

| Backend | Use case | Cost |
|---|---|---|
| FinBERT (local) | Per-article sentiment (high volume) | Free |
| Ollama Qwen2.5-7B-Instruct (local GPU) | Theme extraction, bulk classify | Free |
| Ollama Phi-3.5-mini (local GPU) | High-throughput cheap classify | Free |
| OpenRouter (Llama-3.1-70B free, Gemma-2-9B free) | Cross-validation, fallback | Free, rate-limited |
| Snowflake Cortex (`SENTIMENT`, `claude-3-5-sonnet`, `llama3.1-405b`) | Daily synthesis, hard reasoning | Snowflake credits |

- All routes configured in `config\llm_routes.yaml` (primary + fallback chain per task).
- All responses cached via `diskcache` keyed by `SHA-256(task, prompt, model)`, 5 GB cap on local SSD.
- Per-backend token-bucket rate limit; on rate-limit/error → automatic fallback.
- All calls logged to `data\llm_metrics.parquet` for tuning.
- Local LLM fine-tuning deferred to v2 (collect labels via Cortex/OpenRouter in v1, QLoRA-tune Qwen2.5-7B in v2).

## 5. v1 Scope (kept narrow)

- **Universe:** 20 NSE + 30 US + 10 crypto + 4 FX = 64 instruments
- **Horizon:** 5-day directional + magnitude bucket
- **Signals:** Technical + Fundamental + Sentiment (FinBERT) + Macro
- **Model:** XGBoost classifier with Platt-calibrated probabilities, walk-forward CV only
- **Rubric:** 4 pillars (Tech / Fund / Sent / Macro), regime-weighted
- **Regime:** 4-state HMM (bull/bear/chop/crisis)
- **Output:** Conviction-gated signals (emit only if conviction > 70 AND regime supportive)
- **Dashboard:** Streamlit (today's signals, rubric breakdown, backtest report, regime monitor, LLM health, data freshness)

## Context — what changed after deeper exploration

Re-reading the code surfaced **4 real blockers** my first plan ignored:

1. **`omni/features/build.py:49` calls `tiers.load_hot(asset_class, ticker)` directly.** It does NOT take prices as an arg. So "reuse `build_for_ticker()`" is wrong — we need a DF-input adapter that bypasses the hot tier, otherwise on-demand has to write to disk first.
2. **`omni/features/macro.py:compute()` reads from `_drive.read_raw()`** — won't work on a fresh box that's never run the batch. We need a "live" macro fetcher that hits FRED+yfinance directly.
3. **`omni/regime/hmm.py:build_regime_features()` needs SPX OHLCV** — also a raw-tier dependency. Same fix.
4. **`walkforward_fit()` defaults `min_train=504`.** A single ticker's 5y history (~1260 rows) gives only ~1.5 useful folds → CV is shaky. For "deep analysis" we lower `min_train` to 252 and use 4 folds.

Plus 3 things the first plan missed:
- **No universal-model bootstrap path.** The universal model trains on features → features need batch ingest → contradicts "on-demand from scratch". Solution: trainer uses the *on-demand fetchers themselves* on 30–50 representative tickers.
- **No data-quality surfacing.** User's earlier question ("how can you be sure data is correct?") had no answer in the prediction card. Add a `provenance` block per prediction.
- **News sentiment is per-row LLM call** (`omni/features/sentiment.py:37`) → 50 articles = 50 LLM hits per query. Add a hard cap (top-25 most recent) and use the cheap route (`bulk_classification` → groq_llama8b/gemini_flash_lite).

## Architectural decision

Two layers, not one:

- **`omni/ondemand/`** — pure, stateless fetchers + a thin orchestrator. Never writes to `tiers`. Caches via `diskcache` only.
- **Existing batch path** — untouched; it remains the watchlist mode that warms `tiers` for favorites and (separately) produces the calibration/decile-lift artifacts shown on the dashboard.

The two share zero state. They share **logic** by both calling the same low-level functions: `omni.features.technical.compute()`, `omni.rubric.scorer.score_row()`, `omni.ensemble.combine.blend()`, `omni.ensemble.gate.apply()`, `omni.regime.hmm.fit()` / `.predict()`, `omni.models.xgboost_5d.walkforward_fit()` / `predict_proba()`.

### Phase B — Live data fetchers (graceful when keys missing)

5. **`omni/ingest/sources/polygon.py`** — `eod_prices(ticker, start, end) -> DataFrame | None`. Returns `None` if `POLYGON_API_KEY` empty. Hard 5/min cap via simple `time.sleep(12.1)` between calls.
6. **`omni/ingest/sources/fmp.py`** — `fundamentals(ticker)` returning the same schema as `omni/ingest/fundamentals.py` (15 fields). Returns empty df if no key.
7. **`omni/ingest/sources/marketaux.py`** + **`omni/ingest/sources/gdelt.py`** + **`omni/ingest/sources/newsapi_live.py`** — each returns `pd.DataFrame[date, ticker, title, description, url, source_name, published_at]`. GDELT has no key requirement (free tier).
8. **`omni/ondemand/macro_live.py`** — `compute_live() -> DataFrame` mirrors `omni/features/macro.py` schema but fetches FRED via `fredapi` (or skips silently if no key) + yfinance `^VIX, DX-Y.NYB, ^TNX, GC=F, CL=F`. Cached 24h, shared across all on-demand calls. **Falls back to `tiers`-based `omni.features.macro.compute()` if cache empty AND keys missing.**
9. **`omni/ondemand/regime_live.py`** — fetches SPX `^GSPC` + macro_live, fits HMM (`omni.regime.hmm.fit`), caches `RegimeModel` for 24h, returns `(model, label_today)`.

### Phase C — Feature build adapter

10. **`omni/ondemand/features_inline.py`** — `build_features_inline(asset_class, ticker, prices_df, fundamentals_df, news_sentiment_df, macro_df, horizons=(5,)) -> DataFrame`. **Copy of `omni/features/build.py:build_for_ticker` body but takes `prices` as input and skips `persist=True`.** Refactor opportunity: extract the body into a shared helper; for now duplicate to avoid touching the batch path. Single-ticker output, ~1260 rows.

### Phase D — Lookup orchestrator

11. **`omni/ondemand/lookup.py`** — `lookup_ticker(ticker, asset_class) -> LookupBundle`:
    - `prices`: yfinance (always); cross-check vs polygon if available — record `prices_agreement_pct` = % of last-30-day closes within 0.5%
    - `fundamentals`: yfinance + FMP merge (FMP wins on conflicts)
    - `news_raw`: union of NewsAPI + Marketaux + GDELT, dedup on (title, date)
    - `news_sentiment`: cap to top-25 by recency, score via `route("bulk_classification", ...)` (cheap), aggregate via `omni.features.sentiment.aggregate()`
    - reuse `macro_live.compute_live()` + `regime_live.fit_or_load()` from cache
    - Each section caught individually — failure of one source doesn't crash the bundle. `bundle.provenance` records what succeeded.

### Phase E — Universal model (offline bootstrap)

12. **`scripts/train_universal_model.py`** — one-time script:
    - Hardcoded list of 30 reps (e.g. AAPL, MSFT, JPM, XOM, RELIANCE, TCS, BTC, ETH, EURUSD, ...)
    - For each, call `lookup_ticker()` then `build_features_inline()` → pool → call `walkforward_fit(pooled, min_train=2520, n_folds=5)` (high min_train OK — pooled sample is large)
    - Persist last-fold `model + calibrator + feature_cols` to `data/models/universal_5d.joblib` via `joblib.dump`
    - Idempotent; skipping if file <7 days old unless `--force`
13. **`omni/ondemand/model_registry.py`** — `load_universal() -> (model, cal, feature_cols)` cached in-memory once per process; raises a clear "run scripts/train_universal_model.py first" error if missing.

### Phase F — Prediction orchestrator

14. **`omni/ondemand/predict.py`** — `predict_ticker(ticker, asset_class) -> PredictionCard`:
    - `bundle = lookup_ticker(...)`
    - `feats = build_features_inline(...)` → keep the **last row only** for scoring
    - `model, cal, feat_cols = load_universal()`
    - Align: `X = feats.tail(1).reindex(columns=feat_cols, fill_value=np.nan)`; impute NaN with column-medians stored alongside the joblib
    - `proba = cal.predict_proba(X)[:, 1]`
    - Build single-row signal frame, call `assemble_signals(feats.tail(1), proba_up=Series([proba]), regime_override=Series({today: regime_label}))`
    - Generate "why" via `route("signal_explanation", prompt)` (groq_llama70b primary)
    - Return `PredictionCard` dataclass with: `ticker, asset_class, asof, direction, conviction, blended_p, proba_up, rubric_total, pillars (4), regime, why_text, news_top5, provenance, deep_analysis_available=True`
15. **`omni/ondemand/deepanalysis.py`** — `deep_analysis(ticker, asset_class)`:
    - Same prefix as `predict_ticker`, but instead of universal model run `walkforward_fit(feats, min_train=252, n_folds=4, keep_models=True)` on the **single ticker's** features → take the last fold's calibrator
    - Replace `proba_up` and recompute card; tag `model_kind="walk_forward_per_ticker"` + emit fold-by-fold OOF accuracy in the card
    - Cached 24h per ticker

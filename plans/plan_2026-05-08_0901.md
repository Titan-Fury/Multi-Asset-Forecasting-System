## Implementation steps

### Part A — Sub-daily / intraday microstructure

1. `omni/ingest/intraday.py` — stateless `fetch_intraday_bars(asset_class, ticker, interval="5m", days=5)`; ccxt for crypto, yfinance otherwise. Cached at `TTL.news_30min`.
2. `omni/features/intraday.py` — `compute_intraday_features(bars, last_daily_close)`: `intraday_return_pct`, `gap_open_pct`, `vwap_dev_bps`, `opening_range_breakout`, `intraday_realized_vol`, `last_hour_return_pct`, `volume_z_today`, `range_compression`. Safe-default zeros.
3. Wire into `predict.py`: 8 new `PredictionCard` fields + bounded 1d-probability tilt:
   `proba_1d_adj = clip(proba_1d + 0.5*tanh(intraday_return_pct/2 + vwap_dev_bps/200), 0.02, 0.98)`.

### Part B — Cross-asset hedging / pair signals

4. `config/benchmarks.yaml` — ticker → benchmark map (sector ETFs + broad market for US/India, BTC for crypto).
5. `omni/features/pair.py` — `compute_pair_features`: rolling beta_60d, alpha_60d, residual_z_20d, correlation_60d (joinable into training set).
6. `omni/ondemand/pair_signal.py` — runtime scorer: cached `predict_ticker(bench)`; `predicted_alpha_pct = move_5d_pct(stock) − move_5d_pct(bench)`; `pair_sharpe ≈ alpha / residual_vol_20d`. Suggestion fires when `|alpha|>0.5%` AND `pair_sharpe>0.3`.
7. `predict.py` — add `pair_signal: dict` field; never raise.

### Part D — AUC lift (target 0.50 → 0.55+)

20. **Cross-sectional rank target** — `omni/features/targets.py`: add `rank_target_5d` = pct rank of forward return within `(date, asset_class)`. New regression head `XGBRegressor` with rank loss. Optionally also keep binary head and average.
21. **Purged K-fold + embargo CV** — `omni/cv/purged_kfold.py` (de Prado): drops samples whose horizon overlaps fold boundary, plus embargo of `horizon_days` after fold-end. Replace walk-forward in `scripts/train_universal_model.py`.
22. **Stacking ensemble** — `omni/models/stack.py`:
    - Base learners: XGBoost (current), LightGBM, CatBoost (all use rank-target).
    - Out-of-fold predictions from purged CV → ridge / logistic meta-learner.
    - Save as new `UniversalModel` kind `"stack_h{horizon}"`.
23. **Triple-barrier targets** — `omni/features/triple_barrier.py`: vol-scaled up barrier, vol-scaled down barrier, time barrier = horizon. Label ∈ {-1, 0, +1}. New optional training mode `--target=tb`.
24. **Meta-labeling** — `omni/models/meta_label.py`: takes primary signal + features, secondary classifier predicts whether the primary call would have been profitable; multiplies into final conviction.
25. **News embeddings** — extend `omni/llm/backends/finbert.py` with `embed_headlines(texts) -> np.ndarray` returning 768-d CLS vectors. Daily aggregator: mean-pool + max-pool → PCA-32 (fit on train, persisted) → 64 new features. Cached on disk per (date, ticker).
26. **Conformal prediction** — `omni/models/conformal.py`: split conformal on the validation set produces calibrated `(low, high)` intervals at 1d/5d/21d. Replaces hand-rolled ±1σ in `predict.py`.
27. **Fractional differentiation features** — `omni/features/fracdiff.py`: minimal `d` such that ADF stationary, applied to log-prices and log-volumes; appended as features.
28. **Mixture-of-Experts by regime** — `omni/models/moe.py`: 4 specialist gradient-boost heads (bull/bear/chop/crisis) trained on subsets; gate = HMM regime probability. Output = expectation over heads.
29. `scripts/train_universal_model.py` — orchestrator updated: `--target {binary,rank,tb}`, `--ensemble {single,stack,moe}`, `--cv {walkforward,purged}`, `--use-news-embeddings`. Saves model bundle with metadata.
30. `omni/ondemand/model_registry.py` — load any of the new model kinds; `predict.py` selects best by held-out AUC.

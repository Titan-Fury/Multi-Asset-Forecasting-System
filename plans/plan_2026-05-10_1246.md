### Implementation steps

#### MODELING TRACK (~700 LOC)

**M1 — U1: Per-ticker residual head** (~150 LOC)  
File: `omni/models/residual_heads.py` (new)
- Group `WalkForwardResult.predictions_frame()` by ticker.
- Per ticker with ≥ 50 OOF rows, fit a small Ridge regression on the OOF residuals against ticker-specific feature subset (last-N-days returns + microstr score + sent_mean_z).
- Persist to `data/models/residuals/{horizon}d.joblib` as `dict[ticker -> {weights, intercept, feature_names, n_train}]`.
- Inject hook at `scripts/train_universal_model.py:214` — runs once after universal fit.
- Inference helper `apply_residual(ticker, X_one, h) -> delta_p` returns 0 for unknown tickers (graceful).

**M2 — D1: Bayesian shrinkage of deep toward universal** (~80 LOC)  
File: `omni/ondemand/predict.py` (edit `deep_analysis`)
- After deep_analysis computes `proba_deep`, also compute `proba_universal` from the same row.
- Shrinkage weight `w = sqrt(n_deep_train / (n_deep_train + 252))` — small training set → mostly universal; long history → mostly deep.
- Blend: `proba_final = w * proba_deep + (1-w) * proba_universal`.
- Card displays both numbers + the shrinkage weight in a small "(deep 0.62 ⟶ shrunk 0.58 with weight 0.74)" caption.

**M3 — D3: Cross-ticker pooled CV in deep_analysis** (~150 LOC)  
File: `omni/ondemand/predict.py` (edit `deep_analysis`) + `omni/ondemand/peer_finder.py` (new)
- New `find_peer_tickers(target, k=5)` — picks top-k correlated tickers from the universe by 60-day return correlation, cached 24h.
- Concatenate the target's history with peer histories (with a `is_target` indicator feature) before walk-forward.
- Walk-forward sees ~6× more rows → variance drops dramatically.
- Model still predicts only on target's last row.

**M4 — Wire conformal calibrator into predict** (~50 LOC)  
File: `omni/ondemand/predict.py` (edit `_build_card`)
- Already-existing `conformal.fit_interval_calibrator()` is unused. Fit it once during retrain on the universal OOF predictions (saved alongside the model).
- At inference, replace the heuristic ±σ bands in `_build_card` (lines 188-204) with `conformal.predict_interval(proba, alpha=0.2)` for true 80% coverage.
- Card adds a small "80 % coverage" pill next to the band so the user knows this is calibrated.

**M5 — Soft regime probabilities in blending** (~50 LOC)  
Files: `omni/ondemand/regime_live.py` (already returns `proba_today` dict), `omni/ensemble/combine.py` (edit blender)
- Replace per-row `regime` lookup-with-hard-weights with a probabilistic mix:
  ```
  w_model = sum(p_state * weight_for_state[state] for state in {bull,chop,bear,crisis})
  ```
- Smooths transitions at regime boundaries (currently a hard step from 0.60 → 0.45 the day the HMM flips).
- Phase-19 banner in `components.py::regime_banner` already shows the probability bar — now it actually drives blending.

**M6 — A6: Conditional drift gating per scope** (~180 LOC)  
Files: `omni/modeling/drift_gate.py` (extend), `scripts/daily_backtest.py` (extend), `omni/ondemand/model_registry.py` (extend)
- Drift detector runs per (horizon × asset_class) instead of per horizon only — 12 streams instead of 3.
- `needs_retrain.json` becomes a per-scope dict; `model_registry.load_horizon(h)` reads `last_modified_at` and warns in the dashboard if any active scope has been drifted for > 7 days without retrain.
- Adds a small "Last drift" pill on the regime banner: `🟢 stable` / `🟡 drift detected 2d ago` / `🔴 drift unresolved 11d`.

# scratch/

**Not committed to git.** Local-only directory for one-off debug /
exploration scripts (`_diag_*.py`, `_smoke_*.py`, `_verify_*.py`, etc.).

Use this for short-lived investigation code. If a script becomes
permanent and reusable, promote it to `scripts/` and rename it
without the leading underscore.

Files matching `_*.py` are gitignored everywhere in the repo.
